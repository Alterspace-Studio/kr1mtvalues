# kr1mtvalues

- `index.html`을 열면 된다. 데이터는 `data/items.js` 하나.
- 가치는 젬(💎) 단위.
- 사이트 주소: https://Alterspace-Studio.github.io/kr1mtvalues/ (GitHub Pages, main 브랜치)
- 저장소: https://github.com/Alterspace-Studio/kr1mtvalues
- 파일 하나로 묶기: `python3 tools/build_artifact.py` → `dist/kr1mtvalues.html`
- 사전 조사: `RESEARCH.md`
- 이미지: 게임 내 아이콘 `images/<id>.png` (mtsvalues.com 아이템 페이지에서 받음)
